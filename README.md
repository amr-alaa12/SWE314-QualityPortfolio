# Library Management System


## Project Information

### Project Name
Library Management System

### Team Members
- Amr Alaa

### Project Description
The Library Management System is a web-based Minimum Viable Product (MVP) developed using AI-assisted software development. It allows users to log in, search for books, view book details, borrow available books, and return borrowed books. The project demonstrates the use of prompt engineering to improve AI-generated software and serves as the foundation for applying Software Quality Assurance concepts.

---

# Software Classification

### Software Type
Web Application

### Product Type
Generic Product

This system is designed as a generic software product that can be used by different libraries with minimal customization.

---

# Initial Quality Analysis

## 1. Reliability
Reliability is important because the system must correctly record book borrowing and return operations. It should consistently maintain accurate information about book availability and user transactions.

## 2. Security
Security is essential to protect user accounts and prevent unauthorized access to library information. Proper authentication helps ensure that only authorized users can access system features.

## 3. Usability
Usability is important because students and librarians should be able to navigate the system easily. A simple and intuitive interface improves user experience and reduces the learning curve.

---

# Possible Software Risk

One possible quality risk is unauthorized access to user accounts. If authentication is not properly implemented, attackers may gain access to personal information or modify borrowing records.

# AI Development Process

### AI Tool Used
ChatGPT

### Final Prompt
The final prompt requested a complete and well-structured Library Management System using HTML, CSS, JavaScript, PHP, and MySQL. It specified a responsive user interface, proper project organization, input validation, user authentication, database integration, clean and commented code, and good programming practices.

### Prompt Improvement
The first prompt requested only a basic Library Management System with core functionality. The improved prompt added detailed technical and quality requirements, including responsive design, better project structure, code organization, validation, error handling, and database management. These improvements resulted in a more complete and maintainable software system.
